설정 화면

카드 우측 상단 톱니를 누르면 뜨는 설정 대화상자입니다. 확장은 같은 index.html을 ?dialog=1로 다시 열어 폼을 그립니다.

설치 방법

  1. super-kpi-card.trex 파일을 받습니다. 여기서 내려받기
  2. Tableau Desktop에서 워크시트를 하나 엽니다. 대시보드가 아니라 워크시트입니다.
  3. 마크 카드 드롭다운에서 확장 프로그램 추가를 고르고 .trex 파일을 선택합니다.
  4. 연속형 측정값을 Measure 선반에, 날짜 필드를 Date 선반에 올립니다. 날짜는 선택입니다.
  5. 카드 우측 상단 톱니에서 집계 방식 · 접두 접미 · 소수 자리 · 색상을 조정합니다.
Tableau 2024.2 이상이 필요합니다. 뷰 확장은 Extensions API 1.11부터 지원됩니다. 확장 본체를 GitHub Pages에서 불러오므로 네트워크 연결이 필요합니다.

매니페스트가 정의하는 선반

<worksheet-extension id="com.vizyourdata.superkpi" extension-version="1.1.0">
  <min-api-version>1.11</min-api-version>
  <source-location>
    <url>https://tableauops.github.io/kpi-card/index.html</url>
  </source-location>

  <encoding id="measure">          <!-- 연속형 측정값 1개 -->
    <data-spec><data-type>numeric</data-type></data-spec>
    <role-spec><role-type>continuous-measure</role-type></role-spec>
    <fields max-count="1"/>
  </encoding>

  <encoding id="date">             <!-- 날짜 1개 · 선택 -->
    <data-spec><data-type>temporal</data-type></data-spec>
    <fields max-count="1"/>
  </encoding>
</worksheet-extension>

동작 방식

  • getVisualSpecificationAsync()로 어떤 필드가 어느 선반에 올라왔는지 읽습니다.
  • getSummaryDataReaderAsync()로 워크시트 요약 데이터를 페이지 단위로 전부 가져옵니다.
  • 날짜를 일 · 주 · 월 · 분기 · 연 단위로 잘라 버킷을 만들고, 최신 버킷 값과 직전 버킷 값을 비교해 증감을 냅니다.
  • 설정값은 tableau.extensions.settings에 문자열로 저장되어 통합 문서에 함께 남습니다.
  • 데이터가 바뀌면 SummaryDataChanged, 설정이 바뀌면 SettingsChanged 이벤트로 다시 그립니다.

Retention Matrix와 비교

Super KPI Card

  • 선반 2개: Measure(필수) · Date(선택)
  • 값 하나를 크게 보여주는 카드
  • 설정 대화상자로 색 · 형식 조정
  • 설정값을 통합 문서에 저장
  • 집계는 Tableau 요약 데이터에 의존

Retention Matrix

  • 선반 2개: User · Event Date
  • 코호트 행렬 + KPI 카드 4개
  • 확장 안 드롭다운으로 비교 기준 선택
  • 설정 저장 없이 데이터에서 매번 계산
  • 코호트 계산을 확장이 직접 수행

둘 다 <worksheet-extension> 구조에 .trex 하나로 배포하고, 본체를 GitHub Pages에서 불러오는 방식이 같습니다. 다른 점은 계산을 Tableau에 맡기느냐(KPI Card) 확장 안에서 하느냐(Retention Matrix)입니다.

화면은 Extensions API 목을 물려 브라우저에서 렌더한 것입니다. Tableau 안에서 실행한 화면과 카드 자체는 같고, 감싸는 워크시트 영역만 없습니다.
