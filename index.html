  • 같은 프롬프트를 프로젝트마다 다시 입력
  • 앞 답변이 길어지면 순서 누락

남지 않는 결과

  • 중간 산출물이 대화 안에 흩어짐

2.3 Agent · Rule · Skill

프롬프트 입력 대신 역할과 기준 미리 정의

AGENT

단계별 역할

단계별로 읽을 것과 남길 것을 사전 정의. 사람이 순서를 기억할 필요 없음
